# Reused contracts

The new data classes call `reference_planes::base` with the existing ordinary
layout and its default-plane option disabled. The old nine class readers and
owned baselines stay selectable through their existing exact dispatches.
The eighteen-class role is tested as the union of those nine names and nine
independently assembled complete new bodies.

Geometry uses the canonical finite wrapper role and the existing binary64
vector reader. Point/surface data reuse the reviewed finite surface and point
roles. Angular dimensions reuse the complete display-dimension reader. Class
bindings use the existing immutable `DirectReader` function type; operations
retain their own object maps and budgets.

Fixtures reuse the shared wire map, complete plane base, reference-geometry
header, full wrapper/surface/point bodies and angular-dimension builder.
Independent primitive observations come from real scoped source readers.
Owned stream construction and edit contracts reuse the public identifier-test
helpers, preserving actual document context and all unrelated roots.

The flag view follows the existing immutable derived-view pattern. Its paths
are owned, raw bytes remain stored in the archive and equality with one is
computed without changing storage. Empty collections and malformed recognized
fields have separate successful and typed-error outcomes.
