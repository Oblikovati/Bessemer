# Cone references

The later [body-reference extension](../stock-features/README.md) adds complete
caller fixtures for the twenty-first wrapper class. The cone corpus and its
original twenty-class composition remain unchanged.

Feature #54 implements `moConeRef_w` from clause 11.341 / C-383. The installed
primary vtable `0x4D17E050` binds serializer `0x4C27B750` and proves the surface
and reference-wrapper ancestry. The ordinary modern body reuses the complete
surface base, then reads point +C8, vector +E0 and doubles +F8 and +100. These
are exactly eight raw doubles, with no cylinder optional-frame word. Historical
conversion and pre-0x8F0 layouts remain outside the supported context.

The cone is accepted in documented surface, surface-axis and generic wrapper
roles. Unrelated runtime classes retain the existing finite checks. Values
retain all IEEE bits, including signed zero, NaN payloads and infinities;
geometry and scalar meanings remain uncredited.

Independent fixtures cover 162 graphs, 9,171 primitive observations and 21 owned
streams across nine wrapper-version boundaries, three raw-value sets and six
fresh/shared/null caller styles. Three edited goldens change only the final
cone double. Tests check every field, byte, map slot, truncation, extra byte,
old context, suffix width, absent frame word and public input isolation.

Run `cargo test --lib cone_reference_tests`, `cargo test --test resolved_cone_references`
and `cargo xtask pr`. Regenerate with
`python -B -X utf8 -m unittest discover -s docs/features/cone-references`.

Ninety additional graphs and thirty owned streams cover all three end-specification
callers, all four intersection fields and external sketch entities. Existing
wrapper-family vectors remain byte-for-byte unchanged; their coverage gates
combine those fixtures with the new exact cone callers to prove twenty classes.
