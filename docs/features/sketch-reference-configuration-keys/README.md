the qualified configuration-object lookup key and `unknown_70` carries the

i32 value. Neither key is the current-configuration moNode ID, a feature or

establish a numeric-domain restriction or an initializer.

projection, runtime lookup, allocation, reset or ID generation. Existing
loaded owner78 entries are not proven homogeneous; the record interpretation
requires the concrete receiver and provider qualifications in the report.
