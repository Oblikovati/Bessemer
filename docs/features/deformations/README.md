# Deform features

Issue #54; feature behavior version 1. Section 11.357 / C-399 binds the
complete ordinary modern deform feature, direct matching records, versioned
geometry body and final direct edge/face keeper. The inherited body-feature
concept hooks are retained. All temporary arrays are serialized even though
native loading later discards them. Stored words and floating-point bits
remain unchanged before native normalization; raw meanings remain partial.

The feature version at +8D0 controls its optional arrays/words, both matching
passes and extension loop. The geometry version at +134 controls its own
cumulative suffixes. These signed values are parsed once and remain independent
of one another and of the archive version. First-pass matching subcounts are
retained and reused for the later pass, after the geometry body. Nonpositive
counts consume no entries. Positive counts are bounded before iteration.

Geometry prefixes occupy 372 bytes. Cumulative versions reach 380, 396, 516,
576, 584, 588 and 592 bytes. The 120-byte transform uses the existing fixed
operator reader and rejects unsupported perspective bits. Primitive restore
is exactly 56 bytes. Matching subrecords are direct, with a minimum of 112
bytes; the minimum populated first pass is 144 bytes and its version-10 second
pass is 68 bytes. No direct record adds an MFC tag or identity.

Extension codes retain their exact order: 0x3D2 carries i32, 0x13E f64 and
0x1466 an object. Every other signed code terminates the loop after that word;
there is no guessed opaque payload. The final keeper uses its complete existing
direct grammar, including the archive-version gate above 0x3746.

C-399 RTTI proves curve-point endpoint/point/wrapper ancestry and the five-byte
jump to the complete endpoint serializer. Matching preserves original endpoint
and curve-point identities instead of reproducing native ownership conversion.
The exact canonical wrapper family expands from 23 to 24 classes (family
behavior version 2), backed by fresh/cached end, intersection and sketch callers.
Earlier fixture bytes are unchanged. Equality gates require the new class;
no baseline subset or unrelated class is accepted to hide a gap.

primitive observations, 66 geometry bodies, one direct minimum matching case,
