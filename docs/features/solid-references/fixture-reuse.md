# Shared atom-geometry reference fixtures

The independent solid-reference byte builder accepts an optional concrete class
name for the identical modern wire grammar bound by C-248 and C-249. Its default
remains `moSolidRef_w`. Thickening fixtures use `moConstSurfRef_w` through this
parameter; no production reader changes are part of the fixture adjustment.

The existing solid-reference and combine/delete-body regeneration suites passed
unchanged: four Python tests, 333 complete graph cases and 29 containing streams,
including their independent edited goldens. Every byte, primitive observation,
map count and parsed identity remains equal to the previously owned baseline.
The humanizer skill is unavailable; its prose pass remains with the maintainer.
