# Legend step layout switch and runtime availability

Specification14.471 and C-851 bind stored `legend.word_fc` as a raw zero/nonzero
layout switch. The explicit reader stores it from version890103. It supplies
neither a step number nor a universal visibility flag, and older absence is not
initialized to zero. The original native corpus has109 FC observations, all0;
nonzero behavior is static evidence rather than observed native execution.

The complete mode-shape renderer tests its explicit enable argument before
reading legend state. Its first FC read selects the initial vertical position.
Zero uses supplied pointY-sizeY; nonzero also uses the signed runtime12C-124
difference divided by20. The native instructions first subtract in32 bits, then
perform signed constant division. Overflow behavior cannot be replaced by an
unbounded subtraction.

that order. A second FC read selects whether to transform spacing to2*spacing-4.
Later runtime1B0/1B4 conditions can multiply spacing by3. The FC reread occurs
after helper calls; a future layout projection must account for that boundary
instead of assuming an unchanged entry switch or runtime state.
