**Binding and prefix.** `CSWPersistID.Serialization` is export **0x180074DC0–0x180074F3F** in the same hash-bound `cosutilities.dll`. Both read and write branches consume three four-byte integer fields, in order: object **+0x08**, **+0x18**, then signed byte count **+0x0C**. This prefix is **12 + max(count,0)** consumed bytes in the observed native path; negative counts are not a safe interchange contract. An independent bounded reader must validate count, available input and configured limits before allocating.

**Versioned continuation.** The read branch compares the supplied double version with static **840002** at **0x1800A26F8**. The first nonnull result is then used through virtual slot **+0x258** for wrapper reconstruction; this runtime use does not add wire fields. The write branch externalizes wrapper data and always calls `WriteObject` twice after the prefix/blob. Do not infer an older writer layout from the current writer's unconditional calls. These are nested native object archives; the buffer argument is not an object payload length, and the archive version must not be replaced by the outer Simulation version argument.
