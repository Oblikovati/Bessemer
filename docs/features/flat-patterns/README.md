# Flat patterns and bounding boxes

Bessemer reads, edits and writes complete ordinary modern `moFlatPattern_c`,
`moFlatPatBoundBox_c` and `moBoundBoxData_c` records above version `0x27CB` in
non-DB external-XML model archives. Flat patterns reuse the complete body-feature
and common bend-group layers, carrying validated saved helper state into nested
fields. Three direct object arrays retain their serialized nulls, duplicate
references and order before native runtime filtering.

The raw body-presence word controls a kernel frame with no suppression byte.
Present bodies use the existing typed compressed Parasolid partition decoder,
explicit caller schema and aggregate expansion/record budgets. The shared raw
frame entry point also supplies the existing suppression-prefixed reader after
its flag. Unsupported compression forms, invalid lengths/types and absent schema
reject explicitly. An absent body needs no kernel schema.

The direct bounding box consumes its 108-byte data body without an object tag or
map slot. Tagged box and data instances retain normal MFC identities. Vector
order, signed raw words and stored double bits remain unchanged. Independent
version gates select a face pointer, raw word and conditional CString. A saved
helper-state gate selects its own raw word. The signed pair count retains ordered
pairs with repeated keys rather than executing native map insertion.

Independent readers verified 144 complete cases and 44,842 projected primitive
observations. Twelve versions cover every new conditional boundary and inherited
helper boundaries. Both saved states, empty/populated records, absent/present
compressed bodies and both tagged box classes reach exact EOF. Rich cases retain
shared faces, component features, tagged lists, wrappers and strided allowance
payloads. The existing independently observed raw-span projection preserves the
payload bits and source provenance.
Present-body fixtures use a structural single-BODY transmit vector; they prove
framing and typed reconstruction without claiming valid topology.

Four owned streams import the blank part's actual 97 slots and finish with
101, 113, 115 and 115 slots. An independently constructed edit changes only the
direct box's final double from negative zero to 123.5, preserving the compressed
kernel bytes. Public tests reconstruct whole documents under both saved states,
compare that edit and verify input isolation after rejected operations. Private
tests compare every field/byte/slot, reject every prefix and trailing bytes,
exercise malformed counts and pointers, and check raw-kernel context and framing.
Python tests regenerate every fixture and check gates and constructor boundaries.

`reference.json` binds stable before/after sibling reader hashes, generators,
reused builders, primitive oracles and owned fixtures. The schema snapshot retains
the direct-box and raw compressed-body clauses. Existing suppression-prefixed
kernel fixtures remain part of the full regression gate.

explicitly. The unchanged accepted inputs retain the previous independent
