The generator needs the approved sibling source tree. It disables container key
cache discovery, observes the complete model stream and rejects changed sources,
changed input bytes, missing bytes and overlapping reads. Two fresh processes
produced identical oracle bytes. The twelve observer and expected-edit tests also
cover hook restoration on failure, foreign source modules, UTF-16 code-unit
counts and the reviewed fixture layout guard. The oracle retains every final
MFC map slot, including the header's imported external object at index 3.
Repeated imports retain their shared identity; equal but distinct objects remain
distinct. Class slots, null slots and schema words are checked separately.

The first independent baseline is the owned blank part's `Contents/Config-0`.
The reference completes all 24,028 bytes at model version 19000. Its lightweight
section ends at 2921, its resolved section ends at 24028, and the shared map ends
with 97 slots and 36 loaded class names. Header insertion adds one object slot
after the root class/object, preserving the header object's identity. The profile
records exact input/header/source hashes and verified section boundaries.
Unknown-meaning fields account for 16,890 bytes; they are framed fields rather
than an unread remainder. The private Bessemer codec now reproduces this owned
configuration; this does not establish corpus or public API support.

The reference scope is ordinary external-XML model archives. Complete component
helpers require versions above `0x27CB`, a stricter condition than the earlier
part-root prefix's header-import boundary. The library must keep archive mode,
model version, native file context and kernel-carrier context explicit. It must
not infer those modes from nearby byte patterns.

The first Bessemer operation must decode this entire root, force exact typed
construction, change an independently expected field, update section sizes,
replace/reopen the complete document and authentically revert without changing
the header or unrelated streams. A partial prefix, source-byte shortcut or opaque
tail cannot satisfy that operation. Then extend the reader toward all 906 native
part configurations accepted by the scoped reference harness.

Reuse the existing header graph and archive primitives. Header imports append the
self reference and external-reference items in native order, preserving nulls,
duplicates and identities; they do not import the header's entire class map.
Scoped map transitions and section boundaries need owned positive and malformed
fixtures. Pin the existing display corpus before extracting shared infrastructure
and keep structural work separate from layout changes.

The blank root already needs units, node/concept records, visual properties,
model metadata and arrays, direct detail definitions, fixed views, environment
lights, material records and part/exploded-view tails. These serializers belong
to one complete operation. Public model APIs follow that proof rather than
exposing incomplete stages.

The 906-case research harness installs additional scoped feature readers; a

reference adapters and their source hashes when building the corpus gate.
