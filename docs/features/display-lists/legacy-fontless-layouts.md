# Archives before the line-font manager

Reference baseline: specification edition 0.261, dated 2026-10-25, rechecked
against edition 0.262. Its profile additions are outside this checkpoint. All
seven recorded reference-reader hashes remained unchanged.

The 618 complete part and assembly roots cover versions 596, 597, 716, 717, 760,
761, 766 and 767, with 164547 independently expected traced and physical fields.
Through 766 (`0x2FE`), the root omits its line-font-manager pointer and body.
From 767, that graph follows the environment. Root-owned display items remain
independent of this omission.

Removing a graph changes subsequent MFC indices. The independent builder
observes every object-tag position and the complete font-manager span. In these
owned fixtures, the removed subtree occupies map slots 3 through 45: 41 loaded
objects and two class entries. The builder deletes that span and relocates only
observed tag indices. It rejects surviving references into the deleted range.
Stored model/entity IDs, scalar words and payload bytes are not treated as tags.

Tests compare every remaining typed field against the later control after the
measured relocation. They check both new-object and alias targets, physical
class-reference words and loaded-object counts. Additional multi-view fixtures
encode compact references in extended form before reconstruction. Both extended
class references and object aliases must preserve their framing and meaning.
The production decoder uses the existing shared MFC codec; the fixed fixture
slot range is confined to the independent builder and its expected results.

Through 760 (`0x2F8`), populated polygons omit the line-property presence byte
and its conditional embedded record. The builder removes complete records from
their observed spans, including populated styles and absent flags. Coordinates
and all remaining polygon members must match the control. From 761, the raw
presence byte and optional style remain stored.

Sixty-four inline roots each contain two complete facets. Thirty-two independent
facet records exercise legacy arrays with explicit widths four and twenty-four,
capacity, growth, count and known payload bytes. The reference reader consumes
the legacy array before 717 and again through 816; its semantic element domain
remains unknown. Tests therefore preserve each stored width and allow compatible
context changes across 716/717, rather than imposing an inferred element type.
Edits change array metadata and payload alongside other complete-root fields.

Complete edit/revert, truncation and concurrent-construction checks cover the
relocated graphs. Context changes require newly stored line properties and the
font manager. Eight owned containers at 596 and 767 exercise part and assembly
replacement, reopen and revert while preserving unrelated streams. Root and
container verifiers compare forced writes in two fresh processes. Earlier
fixture groups remain unchanged.

The Windows verification run also reconstructed all 1086 native display streams
and 20 native drawing containers exactly in two processes. Both accepted corpus
manifests remained unchanged. Reports beside this note record input, output,
context and runtime source hashes for replay.

This checkpoint admits archive contexts from 596. Earlier bucket, pane and light
layouts, unresolved representations and the broader documented model schemas
remain open. Byte fidelity does not establish geometric validity or native
application acceptance.
