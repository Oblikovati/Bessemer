### 11.433 Entity visual missing-color sentinel and temporary-color separation

*Status: named native setter binding, decoder alias and retained replay.*

The serialized visual color word at `moEntVisProp_c` +8 uses **0xFFFFFFFF** as a missing-color sentinel. Named `setLayer(moLayer_c*, swLayerMask_e)` at `0x4C160B20` tests the layer pointer; on null it writes layer number 0xFFFF and writes color 0xFFFFFFFF when the stored ColorByLayer bit is clear. A set ColorByLayer bit preserves the existing color word on that branch. The existing update routine's -1 check (C-1825) supplies independent sentinel-consumer evidence. This runtime setter behavior is not applied when reading stored data.

`read_moEntVisProp_c` exposes **`color_is_missing`** by exact unsigned equality with 0xFFFFFFFF. `color_word` and `unknown_8` retain all 32 bits. White 0x00FFFFFF and other words with nonzero high bytes do not become the sentinel. The boolean does not assert that a stored color is the effective displayed color or that a layer lookup succeeds.

These are not the serialized +8 word.
