# Reference-geometry fixture reuse

Revolved surfaces use the existing complete reference-geometry wire builder.
Its optional keeper callback inserts the explicit inherited pointer before the
atom fields, with the enclosing object's identity reserved before either body.
The default path retains the preceding bytes, map counts and observations.

The callback is tested by complete revolved-surface records with a real tagged
keeper. Earlier axis, reference-point, connection-point, coordinate-system and
component-geometry fixture regeneration checks protect the default path. This
fixture change is committed separately from the runtime readers. No existing
fixture baseline is regenerated or replaced. The humanizer skill is unavailable;
its prose pass remains with the maintainer.
