# Table, sketch and dimension patterns

Issue #54; behavior version 1. Section 11.352 / C-394 binds six complete
classes in ordinary modern part archives, above 0x27CB, with the enabled
variation baseline and archive condition 0x2000 clear. Saved model/CMgr
state, inherited identities, eligible MBSM and exact EOF remain required.

Table and sketch patterns reuse the complete common pattern body. Dimension
patterns select their documented advanced variation serializer, which stores
signed indices before the original-dimension arrays. The shared prefix was
extracted in a separate commit with existing fixture hashes unchanged; see
[the structural baseline](structural-prefix.md).

Sketch maps use the stored flags on the containing node. Nested feature flags
cannot select this branch. Transform arrays retain width, capacity, growth,
count and every raw u32 word. Width zero ends the array; other widths must be
multiples of 120 bytes. Capacity and growth do not impose an invented bound
on the count. These bytes do not claim geometric transform semantics.

Dimension suffixes preserve six complete display pointers, unqualified object
references, direct regeneration records and their conditional strings and
shared lists. Signed nonpositive counts retain their stored value and consume
no entries. Positive counts are bounded before iteration. Pattern instances
retain their complete body-feature base and typed parent identity. The surface
identifier retains its existing embedded entity-ID framing; the all-range
helper has a display pointer and a single wire byte.

The independent fixture corpus contains 468 complete graphs across thirteen
versions and six styles, 185,895 observed primitive reads and 42 complete owned
streams, including six edit goldens. The actual Source readers supply field,
byte and map-slot expectations from an immutable copy. Complete profiles,
shared displays and lists, raw bulk arrays, signed counts and conflicting
containing/nested flags are exercised without preloaded class-only objects.
The Source native regression also checks three public EOF streams, disabled
scope receiving zero coverage and appended-byte rejection. All 34 focused
pattern tests, two raw-word oracle tests and three public document tests passed.
Immutable regeneration reproduced every owned byte. The Windows Rust 1.99.0
`cargo xtask pr` gate passed: 1,134 library tests, 277 doctests and 2,655 total
passing tests across 195 test executables, with three intentionally ignored.

Two native corpus processes returned identical statuses and causes: 896 of
906 configurations completed, up from 893, with new cases 356, 505 and 604.
All earlier successes remained accepted. The ten explicit stops remain
incomplete. An independent Source audit verified exact EOF for all 896
accepted streams, totaling 80,104,107 resolved bytes, after checking the four
input-stream hashes for each configuration.

Evidence is scoped to these documented part classes. It does not establish
whole-document, assembly, drawing or installed-project completion. The
maintainer humanizer skill was unavailable; prose review remains with review.
