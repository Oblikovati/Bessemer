# Stored spline equation profile 1

This additive profile interprets selected roles in an already admitted complete
ordinary resolved-feature archive. It changes no wire grammar, saved-version
admission, raw field label or prior edit behavior.

Selection starts at a revision-bound physical `flags_32c` field. The projection
requires a new `sgSketch` owner, a canonical in-range direct spline occurrence,
an admitted subtype, the equation-presence bit and the exact same-scope six-text,
two-word group. Returned source handles keep duplicate values physically distinct.
Enumeration follows wire order; no equation-bearing spline yields an empty list.
Wrong, foreign or stale selections return typed errors.

The selected getter bindings name saved slots 0–5 as XExpression, YExpression,
ZExpression, declared-character text, RangeStart and RangeEnd. Values retain
`ArchiveString` encoding and length framing. No converted BSTR, parsed bound or
native parameter-presence flag is produced. The saved1E0 option stays a full
signed32 word. The separate compatibility word is read and preserved without a
new setter or normalization.

LockStart and LockEnd replace only32C masks `0x10` and `0x20`. A text edit replaces
one explicitly selected saved slot; an option edit retains its complete signed
domain. Every edit uses the established complete archive reparse and history path,
including wire-sensitive no-op detection. Stored transforms, unrelated flags and
all other fields remain unchanged.

The read publishes unchanged completion, exact source-schema coverage, copied
physical history and zero projected stored-value disagreement. That zero is not
a geometry tolerance. Expressions, API conversions, native setters/providers,
physical units, geometry and external documents remain outside this profile.
Future runtime work must define its own behavior and acceptance; this stored
projection does not emulate it.
