# Reused point-family contract

The production change replaces the three-point reader's singleton point list
with `POINT_REFERENCE_CLASSES`. That existing reviewed set contains the base,
endpoint and loft-sync classes. It adds no global assignability rule, class-body
reader, field, count or public API.

Fixtures reuse the complete nondefault plane base, reference-geometry header,
existing point bodies and shared wire-map builder. Scoped source installation is
resolved from one explicit source root. Negative witnesses use the complete
common wrapper body; source byte validity is kept separate from role validity.
Public document checks reuse the common edit contract. Coordinate-only suites
include the shared module without signed-word callers; the two signed-word
wrappers remain covered by the other integration crates.
