# Reused contracts

Thin features call `body_features::read` with the existing typed extrusion or
revolution kind. Their exact class bindings are separate from those older
suffix-free feature dispatches. Native ancestry extends the existing finite
atom-owner family by these four concrete classes.

The specification uses the existing display-dimension family, radial-dimension
reader and exact scalar codecs. Bend counts reuse the checked-entry helper with
a 12-byte minimum. It bounds remaining bytes and aggregate entries before any
triple is read; the field budget applies to every scalar independently.

Fixtures reuse the independent body-feature header, atom fields, body suffix,
extrusion/revolution suffixes, wire map, complete dimensions and raw scalar
extrema. Actual source readers are installed by the existing object observer;
no extra reader registration or parser stub is introduced. Owned document/edit
checks reuse the shared public contract helpers. Existing owned baselines remain
unchanged.
