# Cut-list folders and inherited folder layers

Bessemer reads, edits and writes ordinary cut-list folders through the complete
atom-body, sub-atom and sub-weld layers in non-DB external-XML part archives
newer than `0x27CB`. Specification 11.176 / C-204 and its supplied native
evidence bind fourteen concrete classes: three shared body-folder entries,
the sub-atom/sub-weld/cut-list entries, and eight shared feature-folder entries.
The evidence retains their primary dispatches, ancestry, node hooks and
zero-valued optional-word selectors, plus the direct property-list constructor.
The installed-module hash was verified against the supplied evidence.

The atom-body folder reuses the complete folder base, material-folder pointer
and cut-list sort options. The sub-atom suffix stores a tagged `suObList`,
a signed word, a nullable feature-wrapper pointer and two signed words in their
documented non-offset order. The sub-weld layer then stores a direct property
list. Its records add no class tags or object-map slots. The cut-list suffix
keeps the component-feature pointer, two words, a raw byte, a plane pointer,
three raw doubles and two final words. The byte adds no padding and retains
values above one. Native post-load updates and property localization are not
performed offline.

The independent reference reader consumed 252 complete graphs through exact
EOF, producing 41,516 primitive observations. The corpus covers all fourteen
classes, three versions and six byte/property modes. It includes null and fresh
references, cached shared material/sort/list/component/plane targets, empty and
populated direct properties, raw floating-point bits and distinct equal folders
with repeated aliases. Source-parsed target classes and identities are checked
separately from byte partitions and map counts. Eighty-six containing streams
begin with the actual document-derived map of 97 slots; two are independent
property-edit goldens.

Seven private tests compare every primitive span, byte and map count, reject
every prefix and extra byte, enforce the old-context boundary, check declared
pointer roles and direct property counts, verify all fourteen minimum bodies,
and retain raw byte values 0, 1, 2, 3, 128 and 255. Three public tests reconstruct
every containing document, match isolated property edits with independent
goldens, preserve five equal neighboring direct records and shared references,
and verify input isolation after source mutation or rejected field-type edits.
Two Python tests regenerate all fixtures and repeat the parsed-identity checks.

Nonnull `moFeatureRefWrapper_c` bodies remain an explicit dependency: the
available specification and reader declare the pointer but do not supply that
class's complete body layout. A focused test rejects a newly tagged instance
instead of assuming an empty body. Native samples documented in C-204 have null
plane pointers; populated planes are independently covered by synthetic cases.
Raw folder meanings, runtime updates, geometric validity, special archive
contexts, application acceptance and full documented-schema parity remain
unproven. No dependency, exported Rust API or package version changed. The
humanizer skill is unavailable; its prose pass remains with the maintainer.

Two fresh native processes agree on every outcome and cause across all 906
configurations, with a stable executable hash. All earlier 732 complete cases
remain complete and two more complete, reaching 734. Five other cases advance
to later explicit dependencies and receive no completion credit. The remaining
172 cases retain failures, so the broad complete-corpus assertion still fails.
An independent immutable snapshot of 1,204 reference Python modules verifies
all 734 accepted streams through exact EOF: 45,307,798 feature bytes, with all
four original input hashes checked per configuration. The temporary source
copy and audit script were removed after their process terminated. Reports
retain the snapshot identity, source hashes, case hashes and exclusions.

The local `cargo xtask pr` gate passed: 605 library tests, four xtask tests,
all integration tests and 265 doctests. Three native opt-in tests remain ignored
in the default gate; both complete-corpus replays above ran explicitly.
