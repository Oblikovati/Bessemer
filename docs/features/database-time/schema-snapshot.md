For an input time record with32-bit componentsY, monthM, dayD, hourH, minuteN and secondsT, the packer computes, modulo2^32, `a = ((((Y+0x44)<<4)+M)<<21) + (D<<16)` and `c = (((H<<6)+N)<<5) + SAR32(T,1)`, then stores`a OR c`. It does not mask or validate each source component. The reader extracts year=`(word>>25)+1980`, month=`(word>>21)&15`, day=`(word>>16)&31`, hour=`(word>>11)&31`, minute=`(word>>5)&63`, seconds=`2*(word&31)`. The default Windows VFS callback uses GetSystemTime and stores its month minus one before packing. Thus its ordinary month component is zero-based; treating this as an ordinary DOS timestamp would shift months. The writer zeroes the56-byte time record and optionally invokes the current VFS callback before packing, without checking that callback's status. Custom callbacks, invalid components, overflow, year wrap and odd-second loss prevent a general calendar or round-trip guarantee.
