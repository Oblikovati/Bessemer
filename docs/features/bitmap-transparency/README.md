# Stored bitmap transparency settings

Feature [#187](https://github.com/Oblikovati/Bessemer/issues/187) tracks
section 11.1627, C-3311, of the SolidWorks specification maintained in
`../inventor-interface/docs/solidworks-file-format/specification.md`.

The saved has-transparency setting (`raw_70`), level parameter (`raw_60`)
and type selector (`raw_6c`) each retain their full signed i32 value.
Their observed zero values do not establish a Boolean, percentage, unit,
range or closed enum. Runtime cache `7C` is not serialized. The typed
stored-setting interface is implemented; actual-output Source replay,
ThreadSanitizer, full Cargo and publication acceptance remain pending.

The existing complete bitmap grammar already preserves these words.
Preparation matched all 15 direct publication pins. Independent byte
binding matched all 12 documented field spans in four complete native
streams. The original report is retained byte for byte under `reports/`.
These checks do not grant combined whole-part accounting credit.

Ordinary PE-file verification matched all 13 retained native byte ranges
(636 bytes in total) and nine typed exports in the installed module.
pefile's parsed export list omitted a required name; direct raw export-name,
ordinal and address tables matched the unchanged expectations. This is not
REA Evidence. No instruction assertions, pure model or native classifier
were rerun, and range equality does not prove complete control flow.

An immutable original Source copy accepted 731 candidate bodies and
rejected all 88,459 truncated prefixes. The cases cover signed extrema,
noncanonical settings, exceptional binary64 siblings, absent planes with
negative pixel dimensions, and present planes with presence values 1 and
255. The first verifier used a 25-byte class-tag offset and failed; the
canonical tag is 26 bytes. Only that expected slice was corrected. The
fixture packet and original reader stayed unchanged.

The complete-stream matrix contains two physical bitmap-data definitions
and an alias per case: 1,462 definitions and 731 aliases. Original Source
accepted all 731 streams through exact EOF and checked the full 34,361-read
primitive partition. Independent checks matched each framed stream to its
body literals. Bessemer reconstructed every stream byte for byte and
matched all six physical setting words per case. Snapshot manifests retain
the source hashes and consumed module origins. A second fresh strict replay
passed without rewriting fixtures; all 167 consumed Source modules were
unchanged. It also checked every literal integer, binary64 sibling, text,
plane and reference-presence value in both physical definitions.

A separate native probe reconstructed all four original streams. Twelve
edits through the existing generic field API matched literal four-byte
patches at the independently pinned offsets and preserved the source.
Unchanged original Source also accepted all four native streams against
their published graph/map fingerprints, root spans, whole-stream unknown
totals, sketch and detail counter signatures, and 12 literal settings.

These probes establish the generic API baseline; typed API evidence follows.
Temporary Rust probes were removed after retaining
measurements and artifact hashes.

Remaining acceptance includes both actual-output Source replays,
ThreadSanitizer, the full local Cargo gate and exact-head publication gates.
Raw64, raw68, raw80, pixel payloads and transforms stay outside the setting
roles. Native classification, image decoding and rendering are separate
operations. No native code executed during these checks.

The initial typed API matrix passed all 39,474 isolated edit requests across
731 complete streams, two physical owners, three roles and nine signed
values. Independent scalar rows and literal complete-stream patches check
every request. Foreign revisions and nonleading handles are rejected; all
public setting types satisfy `Send + Sync`. These initial tests precede
the broader document, native and concurrency gates below.

Reviewed admission tests reject unqualified bitmap schemas with explicit
errors instead of completed empty results. A bitmap-free archive returns an
empty list. The five-test gate also checks exact coverage, fidelity,
diagnostics, derived history and typed foreign/stale errors. Library and
integration Clippy checks passed with warnings denied, and every new
function meets the repository size limit.

The owned document matrix passed 4,386 edits and 4,386 fresh typed reversals
per process, including complete reopen, every typed field, unrelated stream
order and bytes, and exact restoration of the original container. Two fresh
processes using the final executable passed. Their 39,474-operation wire
exports match each other and the initial run byte for byte; independent
literal checks accepted all 35,088 changes and 4,386 no-ops. Actual-output
Source replay remains in progress.

Native typed tests use the existing 906-case BRF1 packet and four independently
pinned span rows. The first archive matrix passed all 108 requests. Its
document test failed at whole-container restoration after discarding the
original document checkpoint, although typed fields and feature bytes had
reversed exactly. The failed log and its hash are retained. The corrected
test retains the original edited builder through serialization and reopen,
matching the documented operation-local replacement contract, and keeps the
exact original-file assertion. Two fresh corrected native runs passed all
108 archive requests and all 12 document edits and 12 reversals per process. Each run checked every
complete typed field and unrelated stream, exact stored-operation contracts
and literal patches at the independent source offsets.

The mixed concurrency matrix passed in two fresh processes: every serial
result matched eight workers across all 731 cases. Each process checked
39,474 changes, 39,474 no-ops, 39,474 foreign edit failures and 78,948 stale

configuration inputs stayed unchanged. Wire exports and compressed full
traces match byte for byte between processes. Independent literal patches
accepted all 5,117 exported roots, and trace framing/EOF checks passed.
ThreadSanitizer and full Cargo/exact-head publication gates remain pending.
