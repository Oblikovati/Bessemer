# Concentric mates and plane sections

Bessemer retains the complete ordinary model-feature prefix of concentric mates,
then their version-gated words, optional vector, ordered reference map, arrays,
lists and conditional limit values. The stored +4BC value selects the final
limit group whenever it differs from -1. Raw signed IDs and floating-point bits
remain unchanged; runtime remapping and mate solving are outside this reader.

Plane sections reuse the complete reference-plane reader. Their directly owned
geometry stores the plane, ten-scalar bounding box, serialized body/attribute
records, border and display point without adding an object tag. Section edges
retain a surface reference and serialized bodies with no attribute lists.
Suppressed bodies do not establish the documented validity-dependent layout and
fail explicitly. Every signed collection count must be nonnegative and fit the
remaining input before iteration.

Section maps retain key/value order, duplicate keys, strings and object identities.
The ordinary section keeper consumes zero body bytes, as established by the
native provider branch and RTTI. Undocumented populated optional mate-data and
component section-body records remain explicit unsupported classes; no empty
body stubs are registered. These boundaries follow C-403 and section 11.361.

Independent fixtures cover 312 complete graphs across four classes, thirteen
file versions and six styles, with 34,243 primitive observations and 27 owned
streams. They include complete inherited geometry, shared references, strict
counts, optional vectors/limits, ordered maps, null visual references and neutral
serialized kernel frames. Two word-edit goldens and one complete edge-body
removal golden exercise public edits without changing the source document.

Nine focused Rust tests, four public save/reopen/edit/isolation tests, immutable
fixture regeneration and the actual two-source native regression passed. An
initial live-source generation was rejected when reference files changed; the
retained fixtures were generated and regenerated from immutable source copies.
Two fresh native processes matched all 906 statuses and causes. Complete typed
reconstruction increased from 885 to 887 configurations, adding 162 and 304
without regressions. The aggregate corpus still fails because 19 inputs remain
incomplete. The independent reader consumed all 77,966,572 resolved bytes of the
887 accepted inputs through EOF, with all four input streams checked against
the pinned manifest. The full local gate passed 1,093 library tests and 277 doctests; 188 test executables recorded 2,595 passing tests and 3 intentional ignores.

Raw engineering meanings, remaining schema branches, other archive contexts and
native application acceptance remain unfinished. The humanizer skill was
unavailable; its prose review is left to the maintainer.
