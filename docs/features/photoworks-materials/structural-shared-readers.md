# Shared scoped-pointer and scalar readers

The decal schema uses the same distinction between fresh-reader scope and
already mapped pointers as PhotoWorks material lists. The pointer helper now
lives in `model_lists`, with the caller's finite fresh-class table and error
operation. Existing PhotoWorks lists still admit only fresh unit components;
null and cached pointers retain their original identities. The unit body uses
the same existing dispatcher target. Invalid fresh classes keep their previous
error operation, class and cause text.

The Python fixture builder's scalar recipe became a function shared by the
material and forthcoming decal builders. Its original word/default choices,
CString encodings and IEEE bits remain unchanged. The extracted implementations
replace their earlier copies. `structural-baselines.json` pins all 27 existing
fixture files before the extraction. All 27 files regenerated byte for byte. The eleven focused Bessemer tests and
workspace Clippy passed.

This is an internal refactor, with no behavior-version change. The maintainer
humanizer skill was unavailable; prose review remains with review.
