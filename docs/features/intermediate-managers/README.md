# Version-11000 configuration managers

Issue #54; behavior version 1. Section 11.322 / C-364 adds the exact reviewed
11000 dialect alongside 18000 and 19000. The original archive version remains
11000 throughout reading and writing. Neighboring versions stay unsupported;
no version is rewritten to borrow a later suffix.

The directly owned configuration record omits +88 at 11000 and +A8 below its
later gate. Its minimum size is 50 bytes at 11000, 52 at 18000 and 54 at 19000.
The base also omits raw +848 and the later base-end fields. Derived raw +CC8
and the final part set are absent. The owned manager ends after the conversion
list, direct CString array, signed +750 and unsigned +754; it has no later
plane/named/set/display-map groups or synthesized default fields.

retain one pointer. Counts preserve nonpositive declarations as empty loops.

factory table, with null and mapped pointers handled normally. Older scenes
admit their verified fresh node-name, visual-property and scene-data bodies.
