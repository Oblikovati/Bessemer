### 11.449 Stored shared-parameter flag and effective dimension sharing

*Status: typed native parameter-pointer binding, sharing predicate and conditional clear; class-scoped decoder projection and retained replay.*

For **moParameter_c and its parameter subclasses**, bit **29** of inherited node runtime **+28** (`flags_28`, mask **0x20000000**) is the stored **shared-parameter flag**. Exact exported `Dimension_c::getParameter` (`0x4B2A41B0`) returns the pointer at dimension runtime +28 as `moParameter_c*`. Exported `Dimension_c::isShared` (`0x4C82AA90`) reads that same pointer and returns true only when it is nonnull and either the pointed object's signed runtime reference count at +10 is greater than one **or** its +28 shared-parameter bit is set. The stored bit alone therefore does not reproduce the effective predicate.

Exported `Dimension_c::shareCount` (`0x4C82B400`) returns the pointed object's runtime +10 count, or zero for a null parameter. Exported `moDimHandle_c::clearSharedParameterFlag` (`0x4C848DF0`) checks for a dimension, tests `shareCount == 1`, obtains the parameter through its virtual getter and tail-calls the node first-word clear helper with **0x20000000**. This independently binds the mask's name and clear operation. The native range evidence retains both return branches of the small `isShared` and `shareCount` functions; it does not stop at their first return.
